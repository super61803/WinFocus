# Cxspsa-Backend

### Tech Stacks

- Laravel v10.0
- PHP v8.1
- Websockets
- MySQL

### Project Setup

1. Install Packages

```
composer i
```

2. Migrate Database

```
php artisan migrate
```

3. Run Websocket Server

```
php artisan websocket:serve
```

4. Run Queue Job

```
php artisan queue:work
```
